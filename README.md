# Autonomous PiCar Control System

A team-based autonomous vehicle project integrating **real-time sensor feedback, motor control, and computer vision** using Python and a Raspberry Pi. We developed and tested a PiCar capable of regulating its speed, detecting obstacles, tracking visual targets, and navigating autonomously.

## How It Works

- Calculated wheel speed in real time using sensor data
- Implemented feedback control for speed regulation
- Used PWM to dynamically control motor speed
- Integrated ultrasonic sensing for obstacle detection and stopping
- Used OpenCV and HSV filtering to detect and navigate toward colored targets
- Evaluated system performance using response time, steady-state error, and FFT analysis
